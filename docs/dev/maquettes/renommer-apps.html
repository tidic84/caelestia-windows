Renommer les applis · recherche plus juste

Certaines applis ont un nom qu’on ne tape jamais (« Outil Capture d’écran », « SteelSeries GG », « Microsoft Teams (work or school) »). La maquette propose un nom affiché plus court et des mots-clés, modifiables par clic droit › Renommer… sur une appli (ou F2 sur l’appli sélectionnée). Capture, Teams et Terminal sont déjà renommées à titre d’exemple. Tapez une recherche ou essayez les suggestions.

Comparatif

editChanger le nom affiché

  • Le nom sous l’icône devient celui qu’on cherche : « Capture » au lieu de « Outil Capture d’écran ».
  • Le tri par nom suit le nouveau nom.
  • Un seul nom par appli : « Terminal » ou « PowerShell », pas les deux.
  • Si l’ancien nom n’est plus cherché, l’habitude de taper « outil » se perd. D’où la règle : l’ancien nom marche toujours.

sellAjouter des mots-clés

  • Plusieurs façons de trouver la même appli : screenshot, snip, capture.
  • L’icône garde le nom de Windows : rien ne change à l’écran.
  • Invisible : on oublie ce qu’on a mis. La ligne « via … » sous le résultat le rappelle.
  • Un mot-clé trop court (« g ») ferait remonter l’appli partout. Minimum 2 lettres.

thumb_upRecommandation : les deux, dans une seule feuille

  • Clic droit › Renommer… (et F2), entrée placée en tête du menu de l’appli et du menu d’un jeu.
  • Le nom d’origine reste cherchable. Un résultat trouvé par lui ou par un mot-clé affiche « via … ».
  • Un mot-clé compte un peu moins que le nom affiché, pour ne pas passer devant une appli qui porte vraiment ce nom.
  • « Tout rétablir » efface le nom et les mots-clés. Rien n’est changé dans le menu Démarrer de Windows.
Côté technique (à vérifier avant d’écrire le code). Rien côté Rust : les noms et mots-clés vont dans Ilot.folders, déjà enregistré par store_set (saveFolders()), comme hidden. Les clés sont les id d’appli ou de jeu, donc ils survivent à apps_refresh. Une appli désinstallée laisse une entrée orpheline, sans effet. Dans AppsPage.qml, une fonction label(a) remplace a.name pour l’affichage et le tri. Dans rank.mjs, search() prend le meilleur matchScore entre le nom affiché, le nom d’origine (−0,5) et chaque mot-clé (−0,5), et renvoie par où l’appli a été trouvée pour la ligne « via ». Les habitudes (usage.json) sont par id : renommer ne les perd pas.
